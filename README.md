# Agribusiness Data Analytics Project (5-Week Internship)

A hypothetical, end-to-end analytics project for **GreenHarvest Agri Co-operative** (Karnataka, India).
All data are **synthetic**, generated by the scripts in `code/`.

## Deliverables (Word .docx) in `reports/`
| Week | Task | File |
|---|---|---|
| 1 | Agribusiness Data Landscape Exploration & Planning | Week1_Agribusiness_Data_Landscape_Exploration_and_Planning.docx |
| 2 | Data Cleaning and Preparation | Week2_Data_Cleaning_and_Preparation.docx |
| 3 | Exploratory Data Analysis and Visualization | Week3_Exploratory_Data_Analysis_and_Visualization.docx |
| 4 | Statistical Analysis and Predictive Modeling | Week4_Statistical_Analysis_and_Predictive_Modeling.docx |
| 5 | Business Insights, Reporting and Strategic Recommendations | Week5_Business_Insights_Reporting_and_Strategic_Recommendations.docx |

## Reproduce
```bash
pip install pandas numpy scipy scikit-learn statsmodels matplotlib
cd code
python 01_generate_raw_data.py      # synthetic raw dataset with deliberate quality problems
python 02_clean_analyse_model.py    # cleaning pipeline, base charts, model comparison
python 03_gantt_and_stats.py        # 5-week timeline chart, ANOVA / correlation tests
python 04_business_insights.py      # revenue, transport share, irrigation scenario, priority matrix
python 05_eda_and_quality.py        # quality scorecard, imputation experiment, EDA charts
python 06_stats_regression.py       # hypotheses, OLS, diagnostics, price model
# optional: rebuild the Word reports (needs Node.js and `npm i docx`)
for i in 1 2 3 4 5; do node build_week$i.js; done
```
Run the scripts in numeric order: each one adds to `data/results.json`, which the report builders read.

## Structure
- `data/` raw CSV, clean CSV, `results.json`
- `code/` Python analysis scripts and Node report builders (`lib.js` = shared formatting)
- `charts/` figures used in the reports
- `reports/` the five Word deliverables
- `SUBMISSION_DESCRIPTIONS.txt` 200+ word descriptions for each submission form
